# Stock Price Predictor - Codec Technologies Internship

## Objective
Predict future stock prices based on historical data using Machine Learning.

## Tech Stack
- Python, yfinance, Pandas, Scikit-Learn, Matplotlib
- Model: Linear Regression

## Workflow
1. Downloaded historical data from Yahoo Finance
2. Used Close price to predict next day price
3. Trained Linear Regression model (80% train, 20% test)
4. Evaluated using MSE
5. Predicted next 7 days

## How to Run
pip install -r requirements.txt
python main.py

## Output
Generates output.png with Actual vs Predicted graph.
