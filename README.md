# TASK 01 - House Price Prediction using Linear Regression
SkillCraft Technology ML Internship

## Objective
Implement linear regression to predict house prices based on square footage, bedrooms, bathrooms.

## Dataset
House Price Dataset with features: SquareFootage, Bedrooms, Bathrooms, Price

## Tech Used
- Python, Pandas, Scikit-Learn, Matplotlib

## Steps Done
1. Loaded and explored dataset
2. Split data into train/test (80/20)
3. Trained Linear Regression model
4. Evaluated using R2 Score and MSE
5. Predicted price for new houses

## Result
Model achieved good R2 Score and can predict prices.

## How to Run
Open notebook in Google Colab and run all cells.
